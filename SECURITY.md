# Security Policy

## Supported versions

Only the latest commit on the default branch is supported. This is a hobby
operating-system project, not production software.

## Reporting a vulnerability

Do not open a public issue for a security problem. Instead, report it privately
to the maintainers so it can be fixed before public disclosure.

Please include:

- A description of the issue
- Steps to reproduce (ideally a QEMU command line and the affected input)
- The impact and any relevant details

## Scope

This project is an educational microkernel. It runs only in emulated/virtual
hardware and is not hardened against hostile inputs. Please keep expectations
proportionate to that scope.
